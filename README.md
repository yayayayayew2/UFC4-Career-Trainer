HOW TO USE
--------------------------------------------------------------
1. Start the game and open Cheat Engine.
2. Attach Cheat Engine to the UFC 4 process.
3. Open the table: UFC4_Gabungan.CT
4. Make sure NUMLOCK is ON.
5. Use the NUMPAD keys below. You can also tick the entries
   manually in the table.

Every feature is a toggle: press once to turn it ON, press
again to turn it OFF.

A notification box appears in the top-left corner of the
screen, so you know it worked even in fullscreen. If you can't
see it, switch the game to borderless/windowed mode.

Press each key once and wait a moment. Don't spam the keys.


CAREER MODE FEATURES
--------------------------------------------------------------
1. WEEKLY POINT (always 100)
   No hotkey. Tick it manually in the table.
   I recommend NOT using it: it can break your career and you
   may have to start over.

2. EVOLUTION POINTS ........ NUMPAD 9
   If your Evo Points drop below 100, they are automatically
   set to 5000.

3. FITNESS ................. NUMPAD /
   Fitness stays locked at PEAK.

4. MOVE EXP ................ NUMPAD -
   Turn it on, then spar or fight. It auto-detects the moves
   you use and boosts their EXP. Keep using a move until it
   reaches level 5.

5. MONEY ................... NUMPAD 0
   If your money is below 30,000, it is automatically set to
   5,000,000.

6. ALL CAREER FEATURES ..... NUMPAD +
   Turns on every career feature at once (including Weekly
   Point). Press again to turn them all off. If you don't want
   Weekly Point, enable the features one by one instead.


STAMINA
--------------------------------------------------------------
Credits: GoldHEN, Portheon. Stamina method based on the
GoldHEN cheat, converted to Cheat Engine.

It locks YOUR fighter's yellow and white stamina only (not the
opponent's). You can enable each one separately.

FIRST TIME (once per game session)
  1. Enter a FIGHT.
  2. Press NUMPAD * to install the stamina hook. Wait for the
     "Stamina hook INSTALLED" notification. Cheat Engine may
     freeze for a few seconds while it scans memory, that's
     normal.
  3. Turn on the stamina you want, one or both. You only need
     to enable them ONCE, they stay on in later fights:
        NUMPAD 8 = YELLOW stamina (unlimited, never tired)
        NUMPAD 7 = WHITE stamina (held at max)

EVERY NEW FIGHT (required)
  1. Press NUMPAD 4 to RESET.
  2. Play for a few seconds so the game detects both fighters.
  3. Select your side:
        NUMPAD 5 = you are on the LEFT
        NUMPAD 6 = you are on the RIGHT

When you see "Player ... side SELECTED", stamina is working for
your fighter. If you skip the reset + side selection in a new
fight, stamina may not work correctly. Just repeat the steps.

MANUAL PICK (backup): NUMPAD 1 / 2
  Use this only if side selection (5/6) fails.
  Press 1 to test an object (its stamina drops to 20). If YOUR
  bar drops, press 2 to select it. Otherwise press 1 again.

TROUBLESHOOTING
--------------------------------------------------------------
- "FAILED to install": you are not in career mode / a fight
  yet. Enter one, then press the key again.
- No notification visible: switch the game to borderless or
  windowed mode.
- Stamina not working in a new fight: press NUMPAD 4, play a
  few seconds, then press NUMPAD 5 or 6 again.
- Nothing happens when pressing keys: check that NumLock is ON
  and that Cheat Engine has the table loaded.
- Restart the game and reattach Cheat Engine if hooks get
  stuck after switching games or restarting.
